Mods

  • Mod

    LMASTER Mod

    LMASTER is a fix-and-restore mod for Let's Make a Soccer Team! on PlayStation 2 (European release), made and tested on PCSX2. It fixes bugs the game shipped with and brings back features that were switched off.

    It comes in three editions: Lite (fixes only), Full (adds a hidden third tier below each second division, fairer fixtures and the real names and grounds of the 2005-06 season) and Max (Full plus a harder economy and balance changes).

    Version 0.6.0 is pre-release but stable, and some changes still need more testing. You need your own copy of the game: the mod contains no game files and is distributed as xdelta patches.

    Fan-made and non-profit, and not affiliated with or endorsed by SEGA.

    Get it on GitHub
  • Mod

    LMAST Realism Mod

    A texture mod for Let's Make a Soccer Team! on PCSX2. Every Sega-unlicensed team gets era-accurate logos, even on kits, every competition apart from the fake continental cups gets a new logo, and the main six European leagues get full kits. It also adds a new intro and title screen with mod credits.

    Version 2.0 is released.

    Fan-made and non-profit, and not affiliated with or endorsed by SEGA.

    Get it on GitHub
  • Mod

    Motorsport Manager Revamped

    A mod for Motorsport Manager by the MMPC-Revamped Team, combining Ohayoghurt's Vanilla Plus Rebalance (used with permission), Lonewolf Commander's Tyre and Track Variation and my Pyraverse Championships, which makes the championships and their logos new.

    Version 4 adds a modded DLL with many small bugfixes, more in-race crashes, longer safety cars and more votes. It is still unsupported.

  • Software

    Vyvrael-Chess

    Vyvræl is a dragon-flavoured, UCI-compatible chess engine written in Rust, built with AI and playing for the attack. It speaks the UCI protocol, so it's made to plug into chess GUIs and lichess-bot, and a casual-games Lichess bot is planned. It's an early alpha: still weak, and its strength hasn't been measured yet.

    See it on GitHub
